# Rules for every newsletter issue

An issue file must:

1. Start with a line `Subject: ...` of 50 characters or fewer.
2. Then a line `Preview: ...` of 90 characters or fewer.
3. Greet the reader with `{{first_name}}`.
4. Have exactly one main link, written as `[Button text](https://...)`.
5. End with a sign-off, then this two-line footer as plain text:
   - a line that starts `You're getting this because`
   - a line that contains `Unsubscribe: {{unsubscribe_url}}`
